# KatTopBar Version 1.01
## What's new
### TopBar API

| Method | Description |
|---|---|
| `ResetTopbarTransparency()` | Set background transparency to 0.5 |
| `SetTopbarColor(Color3)` | Set background color |
| `GetTopbarColor()` | Get current background color |
| `ResetTopbarColor()` | Set background background color to 31, 31, 31 RGB |

## Common Improvements 
* When using PlayerGui:SetTopBarTransparency, the transparency value is applied to KatTopBar Transparency
  * For example, PlayerGui:SetTopBarTransparency(0.2) now just triggers KatTopBar:SetTopBarTransparency(0.2)
* KatTopBar now throws a warning if required from Server
  * Also, a warning if KatTopBar is already initialized
