# KatTopBar Version 1.02

## What's new

### Text API

| Method | Description |
|---|---|
| `AddText(config)` | Create a text element inside the TopBar |

**Text configuration:**

| Property | Description |
|---|---|
| `Name` | Element name |
| `Text` | Displayed text |
| `Size` | Text element size |
| `Font` | Text font |
| `TextColor` | Text color |
| `Type` | Element alignment: `left`, `center` or `right` |
| `Order` | Element position within its alignment group |
| `Visible` | Set initial visibility |

**Text element methods:**

* `SetText(string)` — Change displayed text
* `SetTextColor(Color3)` — Change text color
* `SetFont(Enum.Font)` — Change font
* `SetSize(UDim2)` — Change element size
* `SetOrder(number)` — Change element order
* `SetType(string)` — Change alignment
* `SetVisible(boolean)` — Show or hide the element
* `Destroy()` — Remove the element

Text elements also support the `Clicked` event.

### Custom Leaderstats API

| Method | Description |
|---|---|
| `AddLeaderstatsColumn(config)` | Create a custom Leaderstats column |

**Column configuration:**

| Property | Description |
|---|---|
| `Name` | Column name |
| `Value` | Displayed value |
| `Order` | Column position |
| `Visible` | Initial visibility |
| `NameColor` | Name text color |
| `ValueColor` | Value text color |

**Column methods:**

* `SetName(string)` — Change column name
* `SetValue(string or number)` — Change displayed value
* `SetOrder(number)` — Change column order
* `SetVisible(boolean)` — Show or hide the column
* `SetNameColor(Color3)` — Change name color
* `SetValueColor(Color3)` — Change value color
* `Destroy()` — Remove the column

Custom columns also support the `Clicked` event.

### Common Improvements

* Added support for text elements alongside buttons.
* Added custom Leaderstats columns with separate name and value labels.
* Added automatic visibility management for custom columns based on screen orientation and resolution.
* Improved element positioning with shared `left`, `center` and `right` alignment groups.
* Leaderstats spacing now accounts for both custom columns and standard CoreGui Leaderstats.
* Improved element restoration when the TopBar gui is recreated.
